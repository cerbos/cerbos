Strict evaluation mode
Setting `engine.strictEvaluation` to `true` policy evaluation errors stop being ignored. When a condition or variable expression raises a runtime error, the affected action is denied instead of the erroring rule being ignored. An error in a variable denies only the actions whose conditions reference it; an error in an imported derived role denies every action evaluated against the scope importing it. The mode applies to both the check and the query planner APIs. Policy tests can be run in this mode as well by passing `--strict-evaluation` flag. See xref:configuration:engine.adoc#strict_evaluation[`engine.strictEvaluation`] for details.
